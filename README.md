# Small Steps — Beta 1.25

A responsive, installable Progressive Web App for stretching, meditation and real-world Happenings.

## What's new in Beta 1.25
- Replaced the app's old/broken logo references with the new Forest Path logo.
- Updated the 180px, 192px and 512px install icons.
- Happenings is represented by the sealed letter in the top-right of Home; open it to reveal the current monthly activity.
- Added three visual themes: **Forest**, **Renaissance** and **Inferno**.
- Added theme-aware artwork, cards, controls, navigation and Happenings letter styling.
- Added the supplied Buy Me a Coffee link to About.
- Tightened text/background contrast across the interface, including dark Inferno surfaces.
- Updated the service-worker cache so the new assets are picked up after deployment.

## GitHub Pages
1. Create a public GitHub repository named `small-steps`.
2. Upload the contents of this folder with `index.html` at the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Open the published URL on a phone.

## Install
- iPhone: open the URL in Safari → Share → Add to Home Screen → Add.
- Android: open the URL in Chrome → menu → Install app / Add to Home screen.

The app stores progress locally on the device/browser.
